Wise Battle

Compétences Clés : Systems & Combat Design Game Balancing Unity C# Multiplayer Architecture Mobile UI/UX
Rôle : Co-Auteur GDD, Game Designer & Développeur Unity C# Stack : Unity 3D, C#, Netcode, Gemini API, Blender Cadre : Projet Capstone 4 Mois (CGI Studio) | Mobile Android

Un RPG médiéval-fantastique 3D en 1v1 au tour par tour où les joueurs importent n'importe quel cours PDF et utilisent des quiz de rappel actif générés par IA comme unique carburant de leur économie d'énergie de combat.

RESULT: Taux de victoire J1/J2 stabilisé à 51% / 49% sur 40+ matchs de test ; élimination totale du spam aléatoire.

public class CharacterDataSO : ScriptableObject {
    public string heroName;
    public int maxHP = 100;
    public int baseAttack = 25;   // Costs 20 Energy
    public int baseDefense = 15;  // Costs 10 Energy
    public BaseSkillSO uniqueSkill; // Polymorphic SO reference
}

public abstract class BaseSkillSO : ScriptableObject {
    public int energyCost;
    public abstract void Execute(BattleContext ctx);
}

public class TimeSpellSkillSO : BaseSkillSO {
    // Aleric (30E): +10s extra quiz timer for 3 turns -> supercharges +T_remaining Energy!
    public override void Execute(BattleContext ctx) {
        ctx.ActiveUnit.ApplyStatus(new QuizTimerBonusEffect(bonusSeconds: 10f, durationTurns: 3));
        ctx.PlayerAnimator.TriggerCast("TimeSpell");
    }
}

Rôle : Solo Game Designer & Graphic Designer Outils : Illustrator, Canva, Équilibrage Tableur Tag : Étude de Systèmes Tabletop Non-Commerciale — Adaptation Fan IP

Un JRPG tactique sur plateau au tour par tour pour 2 à 8 joueurs à travers une boucle de 40 cases reliant les Quatre Villages Cachés, mêlant combat d'escouade Shinobi à main cachée, économie de défense territoriale et 3 modes de jeu.

DECISION: Introduction du « Power Check Territorial » (péage payé UNIQUEMENT si Puissance Totale de l'Équipe Active < Défense du Lieu) et du « Full-HP Turn Reset » exigeant des combos explosifs ou passifs létaux.
RESULT: Tension tactique constante : les joueurs adaptent la composition de leur main active (3 max) au tour 1 pour franchir les territoires ennemis.

QUÊTE #03 // DUEL DE SORCIERS PVP LOCAL 2D — PUBLIÉ SUR ITCH.IO

Magic Words

Compétences Clés : Combat Balancing Procedural Systems Unity C# 2D Pixel Art
Rôle : Solo Game Designer, Pixel Artist & Développeur Unity Stack : Unity 2D, C#, Aseprite Plateforme : PC / Web (Publié sur itch.io)

Un duel de sorciers 1v1 en multijoueur local pixel-art inspiré de Bookworm Adventures, où les joueurs forgent à tour de rôle des mots anglais de 3+ lettres à partir d'un tirage aléatoire pour lancer des déflagrations magiques ou des soins tactiques.

🔬 Journal d'Itération Playtest (Problème → Décision → Résultat)
PROBLEM: Deux problèmes majeurs en playtest : (1) tirages de 9 consonnes rendant le tour injouable, et (2) spam de mots courts de 3 lettres en soin prolongeant les duels indéfiniment.
DECISION: Programmation d'un algorithme C# de sac pondéré garantissant 2 à 3 voyelles minimum par tirage, et courbe exponentielle des dégâts d'attaque surclassant le plafond de soin dès 5+ lettres.
RESULT: Zéro tour mort signalé et durée moyenne de duel ramenée de 14 minutes à 5 minutes intenses.

ARTIFACT 03-B // PROCEDURAL LETTER BAG & CONSONANT-DROUGHT PREVENTION

Algorithme de Tirage à Voyelles Garanties & Logique C#

public List<char> GenerateBalancedRack(int rackSize = 9) {
    var rack = new List<char>(rackSize);
    int guaranteedVowels = Random.Range(2, 4); // Enforces 2-3 Vowels minimum
    while (rack.Count < guaranteedVowels)
        rack.Add(DrawWithDuplicateCap(VowelBag, rack, maxDupes: 2));
    while (rack.Count < rackSize)
        rack.Add(DrawWithDuplicateCap(ConsonantBag, rack, maxDupes: 2));
    return Shuffle(rack); // Zero dead turns in 100% of PvP rounds
}

Balloon of the Countries

Compétences Clés : Mobile UI/UX Turn-Based Pacing Progression Design 2D Game Art
Rôle : Solo Game Designer & Développeur Unity Stack : Unity 2D, C#, Aseprite, Illustrator Plateforme : Mobile / itch.io

Un jeu 2D vibrant de géographie et de stratégie au tour par tour en multijoueur local (Pass-and-Play), conçu pour des sessions mobiles rapides et publié sur itch.io.
